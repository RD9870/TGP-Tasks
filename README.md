## 📁 Folders Breakdown

### Week 1: Software Fundamentals
This week focused on reviewing the basics of programming such as OOP, SDLC and the SCUM methodology, as well as using Trello to manage a project and divide tasks for collaborative projects.
### Week 2: Programming Basics
This week focused on reviewing the basics of HTML and CSS as well as introducing Tailwind CSS framework and the Flowbite library and how to use them in a project.
### Week 3: UI UX
This week introduced the basic principles of UI/UX and how to use Figma to create wireframes and prototypes for mobile apps and websites as well as user flow and information architecture.
### Week 4: Frontend Web Fundamentals
This week focused on reviewing the basics of Javascript and how to combine it with HTML, CSS and TailwindCSS to create a dynamic and responsive website, as well as introducing Typescript and SASS.
### Week 5: Modern Frontend Frameworks - React JS
This week introduced the React framework and how to combine it with TailwindCSS and DummyJSON API to create a responsive and dynamic website with a dashboard.
### Week 6: Databases
This week focused on reviewing the basics of databases, how to normalize them and create their schemas as well as introducing the Laravel framework and how to use it to create a CRUD API.
### Week 7: Backend
This week builds upon the last one continuing to work with Laravel and creating an API as well as using Postman to test the code.
### Week 8: Integration
This week focused on creating a collaborative project that combines everything learned so far to create a full stack website using Laravel, React and Typescript, as well as using Postman to test the backend code and using Trello to manage the team tasks.
### Week 9: Mobile Development Basics
This week introduced the basics of mobile development using the Flutter framework and how integrate an API with the app.
### Week 10: Mobile Development I
This week builds upon the last one and introduces user authentication as well as introducing some useful packages and good file structure.
### Week 11: Mobile Development II
This week focused on creating a collaborative project that combines everything learned the past two weeks and building the backend for the project.
